# copilot-instructions.md

This project uses an agent directive defined in .github/agents/test-journal-logger.agent.md. Any AI or Copilot agent operating in this repository must read that file and follow its instructions.

**Summary of directive:**
- After each prompt, update the JOURNAL.md file in the repository root.
- Each journal entry must include:
  1. The prompt
  2. A summary of changes made
  3. Reasons for changes
  4. Any relevant context
- Entries should be clear, concise, and provide a useful history of modifications.

**Action required:**
- Always consult .github/agents/test-journal-logger.agent.md for the latest agent instructions.
- Ensure all actions comply with the agent's requirements.
